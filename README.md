# Glass Morphism Digital Clock

Pynexia Web Development Internship — Week 1 project.

A bright, frosted-glass digital clock built with plain HTML, CSS and JavaScript.

## Features
- Frosted glass card using `backdrop-filter` over soft animated colour blobs
- Live digital time, updated every second, with date and time zone
- Analog clock with a smoothly rotating second hand
- 12h / 24h toggle (choice is remembered with `localStorage`)
- Fully responsive, respects `prefers-reduced-motion`

## Run
Open `index.html` in any modern browser. No build step.

## Skills used
HTML5 · CSS3 (backdrop-filter, gradients, animations) · JavaScript (Date, DOM) · Responsive design
